```text
trial_id,time_utc,code_sha,calibration_id,config_sha256,arm,target_id,
intent,caller_id,invocation_id,attempt_id,status,already_satisfied,
trigger_confirmed,grasp_confirmed,placement_confirmed,
```

## 7. 故障与恢复验收

故障注入先在 Mock 或无负载受控环境完成，真机时使用现场批准的方法，不在悬空持物时直接断电/强杀。

| 场景 | 应观察到的行为 | 结果 / 证据 |
| --- | --- | --- |
| 观测过期 / 动作中再次 observe | 拒绝旧引用或场景变化 | |
| 标记丢失 / 局部修正超限 | 拒绝继续，结果与停止状态可查 | |
| 无按键反馈 / 双事件 / epoch 变更 | 不误报成功，可能按下时保留未知 | |
| 同一 caller+相同参数重试 | 找回同一执行，不重复动作 | |
| HTTP 超时 | 保留请求与原 invocation，不换 ID 重按 | |
| 动作取消 | 等待终态，核对臂/手实际停止、持物 | |
| 碰撞 / IK 失败 / 基座漂移 | 拒绝或停机；不能自动放宽约束 | |
| DDS/相机过期、CPU 负载 | 检测时延与实际停机/控制交接 | |
| Gateway/手部服务退出或异常 | 实际手臂/手指行为，外部停机能力 | |
| 空抓 / 滑落 / 遮挡 / 放置不明 | 不误报抓放成功，保留必要占用 | |
| 未完成动作后重启 | unknown、不重放、数据库保留 | |
| 重启后持物记录 | 阻止未经核实的新动作 | |
| 人工 reconcile-empty | 先物理停机/空手检查；保留维护证据 | |
| 正常停机 / 备份 / 版本回滚 | 无意外张手/归零；不回滚新执行事实 | |
